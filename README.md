 Project Overview
MajorCarX is a specialized automotive website designed to showcase custom performance builds, high-spec motor repairs, ECU tuning, and body styling services. The project is built using HTML to deliver a functional user interface tailored for automotive enthusiasts.

---

 Website Goals and Objectives
- Establish an online presence for MajorCarX.
- Provide clear information on available workshop and tuning services.
- Display visual media showcasing recent vehicle projects and builds.
- Allow potential clients to easily locate contact details and submit inquiries.

---

 Key Features and Functionality
- Navigation Bar: Global navigation links present across all pages for smooth user experience.
- Service Listings: Detailed descriptions of mechanical and performance tuning offerings.
- Visual Gallery: Uniform showcase of high-performance vehicles and engine bays.
- Contact Form: Structured input form for user inquiries and bookings.

Project Overview and PoE Requirements
The website consists of six primary pages: index.html, about.html, service.html, gallery.html, enquiry.html, and contact.html. 

Technical Implementation and Improvements

1. Navigation and Routing
The root homepage was updated to index.html for seamless root directory loading on GitHub Pages. Global navigation links across all headers and footers ensure complete internal backlinking throughout the site.

2. Interactive Features
Vanilla JavaScript handles dynamic search filtering on the service page, image modal lightboxes on the gallery and service pages, and an embedded Google Map pinpointing the PowerPipes AutoArt physical location in Midrand on the contact page.

3. Form Validation and Security
JavaScript input validation is implemented across both the contact and enquiry forms to enforce mandatory field entries, valid email formatting, and valid phone number length prior to submission. External links enforce secure attributes (rel="noopener noreferrer"), and HTTPS security is enabled via GitHub Pages.

4. Mobile Responsiveness
CSS flexbox, grid layouts, and custom media queries ensure the full site dynamically adapts across mobile, tablet, and desktop viewports, preventing horizontal overflow and element clipping on small screens.

5. SEO Optimization
Search engine optimization is integrated using standard page titles, alternative text attributes on image elements, a robots.txt file, and a complete sitemap.xml file configured for the repository path.
